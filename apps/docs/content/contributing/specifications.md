Every feature starts as a specification in [`crumble-project/spec`](https://github.com/crumble-project/spec/tree/main/features). The spec repository is the source of truth for status.

| Specification                                                                                                             | Status      | Summary                                                                |
| ------------------------------------------------------------------------------------------------------------------------- | ----------- | ---------------------------------------------------------------------- |
| [0001: Group chats](https://github.com/crumble-project/spec/blob/main/features/0001-group-chats.md)                       | Implemented | Conversations with two to six bots in one shared transcript.           |
| [0002: Desktop jobs](https://github.com/crumble-project/spec/blob/main/features/0002-desktop-jobs.md)                     | Implemented | Bot desktops, desktop jobs, and watching and taking control.           |
| [0003: Chat history search](https://github.com/crumble-project/spec/blob/main/features/0003-chat-history-search.md)       | Implemented | Bots search and read their bot chat and group chat transcripts.        |
| [0004: Provider account login](https://github.com/crumble-project/spec/blob/main/features/0004-provider-account-login.md) | Accepted    | Sign in to model providers with OAuth or a device code.                |
| [0005: Learned skills](https://github.com/crumble-project/spec/blob/main/features/0005-learned-skills.md)                 | Accepted    | Skills, post-turn reviews, cleanup, and reversible learned changes.    |
| [0006: Claude Code provider](https://github.com/crumble-project/spec/blob/main/features/0006-claude-code-provider.md)     | Accepted    | Use a Claude subscription through the official `claude` CLI.           |
| [0007: Credentials](https://github.com/crumble-project/spec/blob/main/features/0007-credentials.md)                       | Accepted    | Placeholders that the server swaps for real secrets on the way out.    |
| [0008: Web app testing](https://github.com/crumble-project/spec/blob/main/features/0008-web-app-testing.md)               | Accepted    | Dev servers, browser tests in coding jobs, and checks in desktop jobs. |
