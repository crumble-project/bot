A bot is an assistant you configure once and keep. It has a name, a model, standing instructions, and one [continuous chat](/concepts/chats) with you. Unlike a chat thread you throw away, a bot builds up memory and skills over time.

Each bot is separate from your other bots. It has its own chat, its own [workspace](/concepts/workspaces), and its own private memory and skills.

## Capabilities

Every bot can have [automations](/concepts/schedules-and-integrations#automations) and run code in code mode. Turn on the rest per bot in its settings:

| Capability       | What the bot can do                                                                                                                        |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **Memory**       | Save facts to its private memory and to memory shared with your other bots. See [Memory and skills](/concepts/memory-and-skills).          |
| **Messaging**    | Ask your other bots questions or hand work to them. See [Messaging other bots](/concepts/schedules-and-integrations#messaging-other-bots). |
| **Coding**       | Start coding jobs that edit files and run commands in its workspace. See [Workspaces and jobs](/concepts/workspaces).                      |
| **Bot desktop**  | Use a graphical desktop with a browser in its workspace. See [Workspaces and jobs](/concepts/workspaces).                                  |
| **Integrations** | Use tools from MCP servers you connect. See [MCP integrations](/concepts/schedules-and-integrations#mcp-integrations).                     |
| **Create bots**  | Propose new bots for your approval in the bot chat. You can edit, approve, or decline each request.                                        |

Coding and bot desktop also need the server to support workspaces. See [Set up workspaces](/self-hosting/workspaces).

## Visuals and reactions

Bots can show stats, tables, and charts inline in the chat, and can react to your message with an emoji instead of a full reply.
