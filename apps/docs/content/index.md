Crumble runs bots on your own server. Each bot has a name, instructions, memory, and skills, and you talk to it in one chat that never resets. When a task needs real tools, the bot works in its own Linux workspace and reports back in the chat.

## Start here

1. [Install the server](/getting-started/server) with Bun or Docker.
2. [Connect a model provider](/getting-started/providers) with an API key or a provider account.
3. [Create your first bot](/getting-started/first-bot) and send it a message.
